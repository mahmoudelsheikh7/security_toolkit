# Security Toolkit (C++) — أداة الأمان للينكس

[English](README.md) | **العربية**

أداة أمان لينكس تعمل على مختلف التوزيعات، بواجهة سطر أوامر واحدة تتيح لك تثبيت أدوات الحماية، وفحص المجلدات والأقراص بحثًا عن ملفات مشبوهة، وتطبيق إعدادات آمنة للجدار الناري. مكتوبة بـ C++17 مع POSIX فقط، دون أي مكتبات خارجية.

المستودع: https://github.com/mahmoudelsheikh7/security_toolkit

## الأنظمة المدعومة

| العائلة | مدير الحزم | الجدار الناري |
|---|---|---|
| Debian, Ubuntu, Mint | apt | ufw |
| Fedora, RHEL, Rocky, Alma | dnf / yum | firewalld |
| Arch, Manjaro, EndeavourOS | pacman | ufw |
| openSUSE, SLES | zypper | firewalld |
| Alpine | apk | ufw |
| Void | xbps | ufw |

يعتمد الكشف على الملف `/etc/os-release` أولًا، ثم يبحث عن أوامر مدير الحزم، لذلك تعمل التوزيعات المشتقة أيضًا.

## البناء والتثبيت

```bash
git clone https://github.com/mahmoudelsheikh7/security_toolkit.git
cd security_toolkit
make                # يضيف -lstdc++fs تلقائيًا عند الحاجة
sudo make install   # اختياري: يثبّت الأداة في /usr/local/sbin
```

أو يدويًا: `g++ -std=c++17 -Wall -Wextra -O2 security_toolkit.cpp -o security_toolkit` (مع GCC 8 أضف `-lstdc++fs`).

المتطلبات: لينكس، و GCC 8+ أو Clang 7+ مع دعم C++17، وصلاحيات root لتثبيت الحزم وضبط الجدار الناري وإدارة الخدمات.

## الأدوات المدعومة (الإصدار 3.0)

| الفئة | الأدوات |
|---|---|
| التدقيق | Lynis, OpenSCAP |
| التحكم في الوصول | AppArmor, SELinux |
| الجدار الناري | UFW, firewalld, nftables |
| منع الاختراق | Fail2ban |
| البرمجيات الخبيثة وحزم الروتكيت | ClamAV, rkhunter, chkrootkit |
| سلامة الملفات والتدقيق | AIDE, auditd |
| مراقبة الشبكة | Suricata, Wazuh, OSSEC |
| أدوات مساعدة | nmap, tcpdump, net-tools, curl, wget, unzip |

ماذا تفعل الأداة لك:

* **شرح كل أداة** قبل التثبيت (وظيفتها والتحذيرات المتعلقة بها)، لتختار ما يناسبك.
* **اختيار أي مجموعة** من الأدوات للتثبيت (بالأرقام أو بالأسماء، أو `rec` للمجموعة الموصى بها).
* **تحذير من التعارض**: AppArmor مع SELinux، أو أكثر من جدار ناري، أو Wazuh مع OSSEC.
* **إدارة كل أداة**: تشغيل الخدمة وإيقافها وتفعيلها، وتشغيل الأداة، وتغيير إعداداتها، وتعديل ملف الإعداد (يُحفظ نسخ احتياطي بالامتداد `.sectk.bak` قبل أي تعديل).

الإعدادات الموجَّهة المتاحة: مدة الحظر وفترة الرصد وعدد المحاولات والقائمة البيضاء وحماية SSH في Fail2ban، ومنافذ UFW و firewalld، وقواعد nftables الأساسية، وقواعد المراقبة وحجم السجلات في auditd، وخيارات rkhunter، ووضع SELinux، وواجهة الشبكة في Suricata، وعنوان خادم Wazuh، والاختبارات المستثناة في Lynis، وخدمة التحديث والخدمة الدائمة في ClamAV.

> Wazuh و OSSEC غير متوفرين في مستودعات التوزيعات المعتادة. تحاول الأداة التثبيت عبر مدير الحزم، وإن لم تنجح فإنها تعرض طريقة إضافة مستودع الجهة المطوِّرة.

## استثناءات الفحص

يمكنك استثناء **مجلدات**، أو **أنواع ملفات** (مثل `.log`)، أو **أسماء وأنماط** (مثل `node_modules` و `*.bak`) من الفحص. تُحفظ الاستثناءات في `/etc/sec_toolkit/toolkit.conf` (للمستخدم root) أو `~/.config/sec_toolkit/toolkit.conf`، وتُستخدم في فاحص الملفات الداخلي وفحوصات ClamAV و AIDE.

```bash
sudo ./security_toolkit --exclusions                       # محرر تفاعلي للاستثناءات
./security_toolkit --scan /home --exclude-dir /home/me/VMs --exclude-ext .iso   # لهذه المرة فقط
```

## تشغيل أدوات محددة فقط، وفحص الأقراص والأقسام بالكامل

```bash
sudo ./security_toolkit --run lynis rkhunter clamav /home   # هذه الأدوات فقط (أسماء أو أرقام أو rec)
./security_toolkit --run scan /var                          # فاحص الملفات الداخلي فقط
./security_toolkit --list-disks                             # الأقراص والأقسام ونقاط التركيب
sudo ./security_toolkit --scan-disks                        # كل أنظمة الملفات المركَّبة
sudo ./security_toolkit --scan-disks sdb sda1 --clamav      # أقراص/أقسام محددة (مع ClamAV)
```

* الأمر `--run` يشغّل الفحص الافتراضي لكل أداة تختارها دون أسئلة. الكلمة `scan` تعني فاحص الملفات الداخلي. الأدوات التي تحتاج اختيارات (مثل ملف التعريف في OpenSCAP) يُفضَّل تشغيلها من `--manage`.
* فحص الأقراص لا يعبر إلى أنظمة ملفات أخرى، فيُفحص كل قسم مرة واحدة. الأقسام غير المركَّبة تُركَّب للقراءة فقط (`ro,noexec,nosuid,nodev`) في `/mnt/sectk-<الاسم>`، ثم تُفحص، ثم يُفصل تركيبها. الأقسام المشفَّرة (LUKS) وأعضاء LVM و RAID تُتخطى مع رسالة توضيحية: افتحها أو فعّلها ثم افحص الجهاز الناتج.
* الخياران موجودان أيضًا في القائمة التفاعلية (8 و 9)، وتُطبَّق عليهما استثناءاتك.

## الاستخدام

```bash
sudo ./security_toolkit                  # القائمة التفاعلية
./security_toolkit --tools               # عرض الأدوات وما تفعله
./security_toolkit --info fail2ban       # شرح أداة واحدة
./security_toolkit --status              # الأدوات المثبّتة وحالة الخدمات
sudo ./security_toolkit --install        # اختيار الأدوات من قائمة
sudo ./security_toolkit --install rec    # المجموعة الموصى بها (أو أسماء: lynis fail2ban ...)
sudo ./security_toolkit --manage fail2ban  # تشغيل، إعدادات، تعديل الملف، التحكم بالخدمة
./security_toolkit --scan /home          # فحص مجلد (لا يحتاج root)
sudo ./security_toolkit --firewall       # تطبيق إعدادات الجدار الناري الآمنة
sudo ./security_toolkit --all /var       # الأدوات الموصى بها + فحص + جدار ناري
```

الخيارات: `-y` أو `--yes` لتخطي رسائل التأكيد (مطلوب عند التشغيل غير التفاعلي)، و `--no-color` لإيقاف الألوان.

## ما الذي تغيّر في الإصدار 2.0 (ما زال مضمَّنًا)

**إصلاح الأخطاء**

* الأوامر `--help` و `--version` و `--scan` لم تعد تتطلب root، فالتثبيت والجدار الناري فقط يتطلبانه.
* القائمة التفاعلية لم تعد تدور بلا نهاية عند إغلاق الإدخال (Ctrl-D).
* رموز الخروج أصبحت رموزًا حقيقية بدل حالة الانتظار الخام لـ `system()`.
* تُنفَّذ الأوامر عبر `fork`/`execvp` دون صدفة (shell)، فلا مشاكل اقتباس أو حقن أوامر.
* لم يعد الأمر `which` مطلوبًا (غير موجود في بعض الصور المصغَّرة)؛ يُبحث في PATH داخليًا ويُضاف `/usr/sbin`، فيعمل `su` بدون `-`.
* فحص المجلدات لا يتوقف عند أول خطأ، ولا يتبع الروابط الرمزية، ويتخطى `/proc` و `/sys` و `/dev`.
* إصلاح سلوك غير معرَّف في `tolower` مع الحروف غير ASCII، واستبدال `localtime` غير الآمن للخيوط، ومشكلة ترتيب التهيئة الساكنة لمسار السجل.
* يتحول السجل إلى `~/.local/state/sec_toolkit/` أو `/tmp` عندما لا يمكن الكتابة في `/var/log`.
* تُحذف رموز الألوان عندما لا يكون الخرج طرفية.

**التوافق**

* إضافة Alpine (apk) و Void (xbps).
* تثبيت apt بلا أسئلة (`--no-install-recommends`، ودون واجهات debconf، وبلا سحب خادم بريد مع rkhunter).
* تفعيل EPEL تلقائيًا في مشتقات RHEL، ورسالة إرشاد خاصة بالتوزيعة عند فشل حزمة.
* لم يعد pacman يستخدم `-Sy` (ترقية جزئية غير مدعومة).
* تفعيل الخدمات على systemd و OpenRC و runit.

**الأمان**

* يُبقي الجدار الناري كل منافذ `Port` في sshd (من `sshd_config` و `sshd_config.d`) ومنفذ جلسة SSH الحالية مفتوحة.
* لم تعد قواعد ufw الحالية تُمسح (أُزيل `ufw reset`).
* لم يعد firewalld يفرض الهدف `DROP` (الذي كان يعطّل ICMP)؛ بل يضبط المنطقة `public` ويضيف SSH.
* تغييرات الجدار الناري تطلب تأكيدًا، ويُفضَّل الجدار العامل أصلًا على إضافة آخر.

**الفاحص**

* يُبلَّغ أيضًا عن الملفات ذات setuid و setgid والقابلة للكتابة من الجميع.

## القيود

* الفحص قائم على قواعد استدلالية فقط: ليس برنامج مكافحة فيروسات، ولا يستخدم توقيعات، ولا يراقب لحظيًا.
* بعض الأدوات موجودة في مستودعات إضافية (EPEL, AUR, security:tools) في توزيعات معينة.
* ضبط الجدار الناري يغيّر منطقة firewalld الافتراضية إلى `public`؛ راجع ذلك قبل استخدامه على خوادم لها مناطق مخصصة.
* لم تُختبر الأداة على كل إصدارات التوزيعات: جرّبها أولًا على جهاز غير إنتاجي، خصوصًا خطوات الجدار الناري على الخوادم البعيدة.

## الترخيص

مقدَّمة كما هي لأغراض تعليمية وبحثية. استخدمها على مسؤوليتك الخاصة.
